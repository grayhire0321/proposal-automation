Proposal Automation

Private tool  •  Grayson Chen

Proposal Automation is a private internal tool. It takes a recipient's email address and a public freelancer profile URL, writes a personalized two-page partnership proposal as a PDF, and shares that PDF from the operator's own Google Drive with the recipient as a viewer.

It is not a public service. There is no sign-up. The only people who connect Google accounts to it are the operator's own accounts, each authorized once through Google's consent screen.

What it does with Google

  • Creates one PDF file in the connected account's Google Drive.
  • Grants the intended recipient viewer access to that file, using Google's own sharing notification.
  • Reads the connected account's email address, to label which account was connected.

What it does not do

  • It does not read, modify or delete any Drive file it did not create.
  • It does not send email. No Gmail access is requested or used.
  • It does not create "anyone with the link" sharing, and never grants editor or owner access.
  • It does not sell, rent or transfer any data to third parties.

Google account access

The tool uses the drive.file scope, which limits it to files it created itself, and userinfo.email to identify the connected account. Access can be withdrawn at any time from Google Account permissions.
