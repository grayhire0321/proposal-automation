Privacy Policy

Proposal Automation  ·  Last updated 19 September 2026

Proposal Automation ("the tool") is a private tool operated by Grayson Chen. It generates personalized partnership proposal documents and shares them from the operator's own Google Drive. It is not offered as a public service and has no user accounts.

Who this covers

Two groups of people appear in the tool: the operator, who connects their own Google accounts to it, and recipients, who are sent a proposal document.

Google user data the tool accesses

  • https://www.googleapis.com/auth/drive.file — to create a single PDF in the connected account's Drive and to grant the intended recipient viewer access to that file. This scope gives access only to files the tool itself created; it cannot see or touch any other file in the account.
  • https://www.googleapis.com/auth/userinfo.email — to read the email address of the connected account, so the operator can tell which account is connected.

No other Google data is requested. The tool does not access Gmail, contacts, calendar or any other Google service.

Limited Use disclosure. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the functionality described above. It is never sold, never transferred to third parties except as needed to provide that functionality, never used for advertising, and never used to train generalized artificial-intelligence or machine-learning models.

Information the tool stores

  • The recipient's email address and the public profile URL entered by the operator.
  • Professional information read from that public profile, and the proposal text generated from it.
  • The generated PDF file.
  • Google Drive identifiers: the created file's id and link, and the sharing permission id.
  • An OAuth refresh token for each connected Google account, encrypted at rest with AES-256-GCM.
  • An operational audit log of the steps performed, for troubleshooting.

Google passwords are never requested, entered or stored. Access tokens and refresh tokens are never exposed to the browser and are excluded from application logs.

Where it is stored

Data is held in a private database and file store controlled by the operator, and is not shared with any third party. The only outbound transfer is to Google's own APIs, to create and share the document.

Retention and deletion

Records are kept while they remain useful to the operator and are deleted on request. To have your information removed, or to ask what is held about you, email the address below and it will be deleted within 30 days.

Withdrawing access

An operator who has connected a Google account can revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access stops all further use of that account immediately. Documents already created in that account's Drive remain in the account and can be deleted there.

Changes

If this policy changes, the revised version will be posted on this page with a new "last updated" date.
